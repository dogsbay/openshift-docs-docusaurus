# Operator Lifecycle Manager metrics {#olm-understanding-metrics}

<a id="olm-understanding-metrics"></a>

Operator Lifecycle Manager (OLM) exposes OLM-specific metrics that the Prometheus-based OpenShift Container Platform cluster monitoring stack can use to track catalog sources, cluster service versions, install plans, and subscriptions.

## Exposed metrics {#olm-metrics_olm-understanding-metrics}

Operator Lifecycle Manager (OLM) exposes certain OLM-specific resources for use by the Prometheus-based OpenShift Container Platform cluster monitoring stack.

**Metrics exposed by OLM**

<table>
<thead>
<tr>
  <th>Name</th>
  <th>Description</th>
</tr>
</thead>
<tbody>
<tr>
  <td><code>catalog_source_count</code></td>
  <td>Number of catalog sources.</td>
</tr>
<tr>
  <td><code>catalogsource_ready</code></td>
  <td>State of a catalog source. The value <code>1</code> indicates that the catalog source is in a <code>READY</code> state. The value of <code>0</code> indicates that the catalog source is not in a <code>READY</code> state.</td>
</tr>
<tr>
  <td><code>csv_abnormal</code></td>
  <td>When reconciling a cluster service version (CSV), present whenever a CSV version is in any state other than <code>Succeeded</code>, for example when it is not installed. Includes the <code>name</code>, <code>namespace</code>, <code>phase</code>, <code>reason</code>, and <code>version</code> labels. A Prometheus alert is created when this metric is present.</td>
</tr>
<tr>
  <td><code>csv_count</code></td>
  <td>Number of CSVs successfully registered.</td>
</tr>
<tr>
  <td><code>csv_succeeded</code></td>
  <td>When reconciling a CSV, represents whether a CSV version is in a <code>Succeeded</code> state (value <code>1</code>) or not (value <code>0</code>). Includes the <code>name</code>, <code>namespace</code>, and <code>version</code> labels.</td>
</tr>
<tr>
  <td><code>csv_upgrade_count</code></td>
  <td>Monotonic count of CSV upgrades.</td>
</tr>
<tr>
  <td><code>install_plan_count</code></td>
  <td>Number of install plans.</td>
</tr>
<tr>
  <td><code>installplan_warnings_total</code></td>
  <td>Monotonic count of warnings generated by resources, such as deprecated resources, included in an install plan.</td>
</tr>
<tr>
  <td><code>olm_resolution_duration_seconds</code></td>
  <td>The duration of a dependency resolution attempt.</td>
</tr>
<tr>
  <td><code>subscription_count</code></td>
  <td>Number of subscriptions.</td>
</tr>
<tr>
  <td><code>subscription_sync_total</code></td>
  <td>Monotonic count of subscription syncs. Includes the <code>channel</code>, <code>installed</code> CSV, and subscription <code>name</code> labels.</td>
</tr>
</tbody>
</table>
