# Deleting applications {#odc-deleting-applications}

<a id="odc-deleting-applications"></a>

You can delete applications created in your project.

## Delete applications using the Developer perspective {#odc-deleting-applications-using-developer-perspective_odc-deleting-applications}

You can delete an application and all of its associated components using the **Topology** view in the **Developer** perspective:

**Procedure**

1. Click the application you want to delete to see the side panel with the resource details of the application.
   1. Click the **Actions** drop-down menu displayed on the upper right of the panel, and select **Delete Application** to see a confirmation dialog box.
   2. Enter the name of the application and click **Delete** to delete it.
2. You can also right-click the application you want to delete and click **Delete Application** to delete it.
