# Updating a cluster in a disconnected environment {#updating-disconnected-cluster}

<a id="updating-disconnected-cluster"></a>

You can update a cluster in an environment without access to the internet by taking additional steps to prepare your environment.

For information about updating a cluster in a disconnected environment, see [About cluster updates in a disconnected environment](/docs/disconnected/updating#about-disconnected-updates).
